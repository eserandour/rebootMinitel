# Outils

Ces outils servent sur un ordinateur : l'IDE Arduino ne compile que les fichiers à la racine du croquis, et ignore ce dossier.

- [`simulateur/`](simulateur/) : exécuter reBASIC sur un ordinateur, sans Minitel (ligne de commande, mode interactif, images d'écran).
- [`tutoriel/`](tutoriel/) : fabriquer le tutoriel « Programmer en reBASIC » (ODT et PDF), dont tous les exemples sont exécutés dans le simulateur.
